# ProofShot

Public-facing ProofShot website and browser demo archived from https://proofshotglobal.pages.dev/.

ProofShot is real-item authentication infrastructure for secondhand trade. It combines live capture, SHA-256 file hashing, public verification links, and Bitcoin timestamp anchoring through OpenTimestamps.

The deployed Cloudflare Pages site refers to a server-side proof store. Server-side worker source and deployment secrets are not exposed by the public website and are not included in this archive.
